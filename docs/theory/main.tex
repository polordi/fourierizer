\chapter*{Cómo leer este documento}
Fourierizer es un instrumento que permite tomar cualquier sonido, ver su contenido en el plano
tiempo-frecuencia, seleccionar las partes que interesan de varios sonidos y sintetizar con ellas un
sonido nuevo. Este documento reúne la matemática que lo hace funcionar, con demostraciones donde
aportan entendimiento. Cada capítulo aterriza sus resultados en decisiones sonoras concretas
dentro de recuadros como este:

\begin{estudio}
Los recuadros \emph{En el estudio} traducen un resultado a lo que oyes y a lo que conviene hacer
en Fourierizer. Si eres productor y no te interesan las demostraciones, puedes leer solo estos
recuadros y las figuras.
\end{estudio}

Todas las figuras y tablas numéricas se generan con el motor de referencia del proyecto
(\texttt{python/fourierizer\_ref}), el mismo contra el que se prueba el plugin. La primera versión
de Fourierizer se desarrolló como tesis de licenciatura~\cite{rodriguez2025}; este texto es
independiente de ella.
